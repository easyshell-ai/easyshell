# 工作流与主机 ACL 发布阻断及部署安全清单

**状态：未完成，禁止发布。** 本文是待验证清单，不是发布说明或上线授权；未勾选事项均为发布阻断。验证结果须记录环境、版本、时间、负责人和脱敏证据，经负责人审核后才能勾选。不得把模拟验证或单元测试当作生产兼容性证明。

## 数据与秘密边界

用户已授权重建本任务的单一隔离测试环境、使用两台测试 VM 并覆盖其 Agent；这不授权
删除其他文件、受保护数据或未经审查的改动。以下数据保护要求按该实际授权范围执行。

- [ ] 严格遵守用户约束：禁止删除测试数据，不触碰现有数据卷；不得通过重建、清空、覆盖、迁移挂载或清理操作绕过限制。任何需要突破边界的操作须先取得用户明确授权。
- [ ] SSH 凭据及其他秘密仅通过批准的秘密管理渠道使用；不得写入文档、命令示例、日志、截图、测试产物或构建上下文。本文和验证证据不得包含凭据或地址。
- [ ] 确认构建上下文及镜像层排除密钥、凭据、环境文件、备份和其他秘密；检查实际构建产物而非仅依赖忽略规则。

## 迁移与兼容性阻断

已在隔离的 MySQL 合成库验证过迁移；**真实旧库数据及并发场景尚未验证**，不能据此判断升级安全。

- [ ] 在经授权的隔离环境中，用受保护的真实旧库副本验证完整迁移、数据保留、约束和访问行为；不得操作现有数据卷或删除测试数据。
- [ ] 验证多实例启动、迁移竞争及运行中请求等并发场景；迁移失败、部分完成或重复执行时必须安全阻断，确认恢复步骤。
- [ ] 部署前停止并隔离所有旧 worker，确认其不能继续消费、调度或写入；在兼容性未经证明前禁止新旧 worker 混跑。记录停机、隔离及恢复确认。
- [ ] 明确验证新旧 schema 与服务、worker 的兼容矩阵及升级顺序；任何不兼容组合必须禁止运行。明确回滚边界，不假设旧版本可读取新 schema。
- [ ] 验证新旧 agent token 代次与服务端兼容矩阵、认证和轮换流程；不泄漏 token，不因升级重建 agent，无法兼容时阻断发布并制定经批准的迁移方案。
- [ ] 验证 ACL 迁移的身份映射、授权范围和幂等性；历史归属或来源为 `unknown` 的记录不得推断为可信或默认放行，须保持拒绝并经授权人工处理。

## 运行时安全阻断

- [ ] 验证审批与高危命令门禁在证据缺失、无效、过期、错绑、重放、查询异常及并发竞争时均 fail-closed，不能派发；确认风险响应与持久化记录不包含命令原文。
- [ ] 确认 code sample 的内存隔离能力未得到可靠证明时保持禁用，不能用超时或其他限制替代内存隔离；启用前须另行完成隔离与资源耗尽验证并获批准。
- [ ] 核验工作流和主机 ACL 的跨用户、跨资源访问及 WebSocket 授权，包含资源不存在和查询异常时拒绝；检查审计与敏感信息脱敏。

## 备份、实施与恢复

- [ ] 在任何部署动作前确认备份完整、受保护且可恢复；在独立隔离环境完成恢复演练并核对数据与权限。备份和演练均不得改动现有数据卷或删除测试数据。
- [ ] 确认部署、失败中止和恢复方案，包括旧 worker 隔离、新 schema 回退限制、agent 身份和 token 的保留；不得重建 agent。无法安全恢复时禁止部署。
- [ ] 部署后在授权范围内核对服务状态、迁移结果、ACL、审批、审计和 agent 连通性；异常立即停止推进并按已验证方案处理，不以删数据或重建 agent 排障。

## 最终验证与放行

- [ ] 在最终候选版本上完成仓库 `AGENTS.md` 要求的全部 server、web 单元与构建、web 视觉、agent、mcp 验证；记录命令、结果及必要环境，失败或未运行均阻断。
- [ ] 在获授权、隔离且不含秘密的数据和环境中，对真实模型完成安全检查：输入输出脱敏、越权与提示注入、结构化输出及失败关闭；不得让模型输出绕过审批或直接产生可执行命令。
- [ ] 在明确授权的真实主机上完成最小权限安全检查：ACL、agent 身份与 token、审批门禁、审计及异常拒绝；不得执行未经批准的破坏性操作或泄漏主机地址与凭据。
- [ ] 所有阻断项均有可复核的脱敏证据，相关负责人确认剩余风险和部署窗口；任何未验证、不兼容或无法安全恢复的事项继续阻断发布。
